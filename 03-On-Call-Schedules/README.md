# PagerDuty On-Call Schedules

## What is On-Call?

On-call defines which engineer is responsible for responding to incidents during a specific period.

## Example

```text
Monday - Friday
     ↓
Engineer 1

Saturday - Sunday
     ↓
Engineer 2
```

## Practical

Create an on-call schedule with multiple engineers.

```text
Engineer 1
    ↓
Primary On-Call

Engineer 2
    ↓
Secondary On-Call
```

This schedule will later be connected to an escalation policy.
