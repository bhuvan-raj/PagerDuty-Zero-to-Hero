# Introduction to PagerDuty

## What is PagerDuty?

PagerDuty is an incident management platform that helps DevOps and SRE teams respond to alerts and manage production incidents.

It connects monitoring and alerting systems with the engineers responsible for responding to incidents.

## Why PagerDuty?

In a production environment, monitoring systems can generate alerts at any time.

PagerDuty helps ensure that the appropriate engineer is notified when an important alert occurs.

```text
Monitoring
    ↓
Alert
    ↓
PagerDuty
    ↓
On-Call Engineer
    ↓
Incident Response
```
