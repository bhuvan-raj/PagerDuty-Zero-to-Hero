# PAGERDUTY

PagerDuty is an incident management platform used by DevOps and SRE teams to manage alerts, incidents, on-call schedules, and escalation workflows.

This repository provides a practical Zero to Hero learning path for understanding PagerDuty and integrating it with Grafana Alerting in a real-world DevOps environment.

## What You Will Learn

- What is PagerDuty?
- PagerDuty Services
- On-Call Schedules
- Escalation Policies
- Incidents
- Grafana Alerting integration
- Alert → Incident workflow
- On-call notification
- Incident acknowledgement
- Incident resolution
- Incident escalation
- Real-world incident management workflow

## PagerDuty Workflow

```text
Application / Kubernetes
          ↓
      Prometheus
          ↓
        Grafana
          ↓
     Alert Rule
          ↓
      PagerDuty
          ↓
       Service
          ↓
 Escalation Policy
          ↓
   On-Call Engineer
          ↓
       Incident
          ↓
 Acknowledge / Resolve
```

Prometheus is used as the metrics source, Grafana evaluates the alert rules, and PagerDuty handles incident management and on-call escalation.

## Modules

### Module 1 — Introduction to PagerDuty
Learn the fundamentals of PagerDuty and understand its role in DevOps incident management.

### Module 2 — Services
Learn how PagerDuty Services receive events and connect them to escalation policies.

### Module 3 — On-Call Schedules
Learn how to configure engineers and define who is responsible for responding to incidents.

### Module 4 — Escalation Policies
Learn how PagerDuty escalates incidents when the current on-call engineer does not respond.

### Module 5 — Incidents
Learn the PagerDuty incident lifecycle:
```text
Triggered
   ↓
Acknowledged
   ↓
Resolved
```

### Module 6 — Grafana → PagerDuty Integration
Integrate Grafana Alerting with PagerDuty and send alerts from Grafana to a PagerDuty Service.

### Module 7 — Real-World Incident Management Lab
Build a complete monitoring and incident-management workflow using Prometheus, Grafana, and PagerDuty.

## Goal

By completing this repository, you should be able to configure PagerDuty for a real-world DevOps monitoring workflow where alerts generated by Grafana are routed to PagerDuty and handled through services, on-call schedules, escalation policies, and incidents.
